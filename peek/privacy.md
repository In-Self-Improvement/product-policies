# Peek Privacy Policy

Effective date: October 19, 2026

This policy describes how the Peek Chrome extension handles information. Peek is maintained by In-Self-Improvement.

## What Peek does

Peek lets you select elements on a web page, write UI change notes, and copy a structured prompt for an AI coding tool. It operates on the current tab when you activate it.

## Information processed on your device

To prepare your prompt, Peek reads the current page URL, viewport size, and information about the elements you select. This may include element HTML and text, CSS selectors, styles, position, and React component names when available. It also processes the notes you enter and pointer or keyboard interactions needed for its interface.

Selected page content and URLs may contain personal or confidential information. Review the copied prompt before sharing it.

## Storage and transmission

Peek keeps notes and selected element information in the current tab's memory. Turning Peek off does not necessarily clear notes; use the Clear button to remove them. Reloading or closing the page clears this in-memory state. Peek does not persist notes to extension storage, browser local storage, or a developer-operated server.

When you click Copy all, Peek writes the prompt to your system clipboard. Copied text can remain there after the page is closed, according to your operating system and clipboard settings. Peek does not read your existing clipboard contents.

Peek does not transmit notes or page content to its developer, an AI service, or another server. It has no analytics, advertising trackers, or account system. We do not collect, sell, or share extension user data.

If you paste the prompt into an AI coding tool or another service, you choose to share that content with that service. Its own privacy policy and data handling rules apply.

## Permissions

- **activeTab:** Allows access to the current tab after you activate Peek, so you can select elements and annotate them.
- **scripting:** Allows Peek to inject its bundled element picker and annotation interface into that tab.

Peek bundles its executable code with the extension and does not load remotely hosted executable code.
